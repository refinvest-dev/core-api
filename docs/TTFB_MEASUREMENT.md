# TTFB 사용자 측정 프로토콜

Phase 1 종료 조건인 Time to First Backtest(TTFB)를 같은 방식으로 측정하고 기록하기 위한 운영 문서다.
이 문서는 제품 계약이나 백테스트 계산 규칙을 변경하지 않는다.

## 목표

- Simple 전략: 첫 `COMPLETED` 결과 화면 확인까지 3분 이하
- Advanced/Cross-market 전략: 첫 `COMPLETED` 결과 화면 확인까지 5분 이하

결과는 과거 데이터 기반 시뮬레이션의 완료 여부와 사용 흐름을 측정하는 용도다. 투자 판단이나 전략의
수익성을 평가하지 않는다.

## 측정 전 준비

1. 측정 대상과 진행자는 동일한 준비 상태의 Web/Core/Compute 환경을 사용한다.
2. 참여자는 로그인 완료 후 `/strategies` 화면에서 시작한다. 로그인·계정 생성 시간은 TTFB에 포함하지
   않는다.
3. 준비된 PRO 테스트 계정을 사용하며, 외부 데이터 공급자·개인 계정·브라우저 확장 프로그램은 사용하지
   않는다.
4. 측정자는 화면, 시작·완료 시각, 막힌 지점만 기록한다. Cookie, Access Token, 개인식별정보가 포함된
   화면이나 로그는 보관하지 않는다.

## 공통 측정 규칙

- 타이머는 참여자가 과제 문구를 읽고 시작 의사를 밝힌 시점에 시작한다.
- 타이머는 결과 화면에서 해당 run이 `COMPLETED`이고 Equity Curve, Drawdown, 결과 요약 중 하나 이상이
  보이는 시점에 멈춘다.
- 진행자는 과제의 의미만 다시 읽어 줄 수 있고 UI 조작 방법이나 조건값 입력 순서는 안내하지 않는다.
- 오류, 페이지 새로고침, 재시도, 도움 요청도 측정 시간에 포함한다. 실패한 세션을 표본에서 제외하지
  않고 실패 사유를 기록한다.
- 각 시나리오는 최소 3명의 참여자로 측정한다. 참여자별 숙련도(처음 사용/재사용)는 함께 기록한다.

## 시나리오

### Simple

참여자에게 아래 과제 문구만 제공한다.

> QQQ가 1,000보다 높을 때 QQQ를 매수하고, 1 Signal Session 보유하는 전략을 만들어 백테스트 결과를
> 확인해 주세요. 기간은 2025-01-02부터 2025-01-08까지이며 수수료와 슬리피지는 0입니다.

기대 흐름은 전략 생성, StrategyVersion 정의, 백테스트 실행, 결과 화면 확인이다. 거래가 없는 결과도
정상 완료로 취급한다.

### Advanced/Cross-market

참여자에게 아래 과제 문구만 제공한다.

> BTCUSDT가 90,000보다 높고 92,000보다 낮을 때 TQQQ를 매수하는 전략을 만들어 백테스트 결과를 확인해
> 주세요. Primary Signal Asset은 BTCUSDT, Lag은 0, 보유 기간은 3 Signal Sessions, 기간은
> 2025-01-02부터 2025-01-08까지, 수수료는 2%, 슬리피지는 0입니다.

기대 흐름은 AND 조건, Cross-market 실행 자산, 기간·수수료 설정, 결과 해석 화면 확인이다. 완료 후
전략 Equity Curve와 Drawdown이 표시되는지 함께 확인한다.

## 판정 및 후속 조치

각 시나리오의 모든 원본 기록을 보존하고, 완료 세션의 최소·중앙·최대 TTFB와 실패 수를 함께 보고한다.

판정한다. 목표를 넘긴 세션은 관찰란의 막힌 단계를 우선순위로 삼아 Web UX 개선 항목으로 전환한다.
