# Account 목록 HTTP 초안의 대체 경로

현재 정본은 [ADR-087 채택 정책](TRADING_REVIEW_ACCOUNT_LIST_POLICY.md)이다.
기존 audience 유지·목록 전용 scope/operation 허용·query/가시성/응답 정책을 확정했다.
이전 초안의 별도 account-list audience는 채택하지 않았다. 이 경로는 기존 링크의 안내로만 유지한다.
[채택 전 고정 초안](https://github.com/refinvest-dev/context/blob/222e908fa84dc429bb7500332c2b80bc07b475f5/docs/TRADING_REVIEW_ACCOUNT_LIST_HTTP_DRAFT.md)은 당시 제안 기록이며 현재 정책이 아니다.
OpenAPI/consumer·runtime 구현과 실제 수용/운영 인계는 후속이다.
